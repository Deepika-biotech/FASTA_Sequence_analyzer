DNA FASTA Sequence Analyzer Using Python and Biopython
## Project Overview

This project demonstrates basic DNA sequence analysis using Python and Biopython. It reads a DNA sequence in FASTA format and calculates important sequence statistics.

## Objective

- Read a DNA sequence from a FASTA file.
- Extract the sequence identifier.
- Calculate the total sequence length.
- Calculate GC content as a percentage.
- Count the A, T, G, and C nucleotides.
- Identify other or ambiguous bases.

## Dataset Information

- Database: NCBI Nucleotide
- Accession Number: MZ005317.1
- Input Format: FASTA
- Organism and gene details: Refer to the linked NCBI record.

"View the sequence on NCBI" (https://www.ncbi.nlm.nih.gov/nuccore/MZ005317.1)

## Tools and Technologies

- Python
- Biopython
- PyCharm
- FASTA file format

## Methodology

1. Obtain a DNA sequence in FASTA format from NCBI.
2. Save the sequence in "Sequence.fasta".
3. Read the FASTA file using Biopython's "SeqIO" module.
4. Extract the sequence identifier and sequence.
5. Calculate the sequence length and GC content.
6. Count each nucleotide and identify other bases.
7. Display the results in the Python console.

## Results

The program calculates the following parameters:

- Sequence ID
- Sequence length in base pairs
- GC content percentage
- Nucleotide composition (A, T, G, C)
- Other or ambiguous bases

## Conclusion

This project provides practical experience in biological sequence handling using Python and Biopython. It demonstrates how simple programming techniques can be applied to extract and calculate basic DNA sequence statistics.
