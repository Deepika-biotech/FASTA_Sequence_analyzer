# FASTA Sequence Analyzer

## Objective
To analyze a DNA FASTA sequence using Python and Biopython.

## Database
NCBI Nucleotide

## Tools
- Python
- Biopython
- PyCharm

## Input
A DNA FASTA sequence of the Borreliella garinii HBB gene obtained from NCBI.

## Analysis Performed
- Sequence identification
- Sequence length calculation
- GC content calculation
- Nucleotide composition (A, T, G, C)

## Results
The FASTA sequence was successfully analyzed using Python and Biopython. The sequence length, GC content, and nucleotide composition were calculated.

## Conclusion
This mini-project demonstrates the use of Python and Biopython for basic DNA sequence analysis.
